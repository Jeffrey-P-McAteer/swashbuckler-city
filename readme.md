
# Swashbuckler City

Swashbuckler City is a Cross-platform QWERTY-and-Controller video game with a number of production goals beyond being barrels of fun to play.

## Goals in no particular order

 - [ ] Windows x64, Window arm64, Linux x64, Linux arm64, MacOS arm64 support
 - [ ] Build all platforms from a single Linux development box
 - [ ] Compile all graphics from source, including fonts
 - [ ] Learn how to design a font & suitable for the game
